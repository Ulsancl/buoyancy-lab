# 릴리스 확인 기준

이 문서는 Buoyancy Lab의 공개 범위를 확인하는 기준입니다. 목록 자체가 완료 기록은 아니며 실제 통과 개수·환경·파일 해시는 각 릴리스의 결과 기록을 따릅니다. 자동 검사나 내부 관찰을 외부 소비자 조사·판매 인증으로 표현하지 않습니다.

- 정적 수치 모형, 실제 형상의 체적, 저장 형식, 원자 저장, 세 실험의 조건 확인을 순수 검사로 검증합니다.
- 실제 조작으로 질량·체적·밀도·높이, 중성/무평형 설명, 안내 완료, 비교 공통 축, 파일·자동 저장 원문 보호, 1600/1024/390px 접근을 검증합니다.
- 힘의 실제 화살표 길이와 방향, 표시값 연결, 0 N과 사용하지 않는 힘, 가까이 보기, 카메라 저장·복원·경계, 명시적 조작 외 시점 불변을 확인하고 실제 화면을 읽습니다.
- 소스 앱과 패키지 앱에서 로컬 파일, BOM·오류·취소, 창 크기·위치 복원, 정상 종료, 기본 사용자 프로필 보존을 확인합니다. 실제 설치와 이전 버전 업데이트의 보존 결과도 구별해 기록합니다.
- 빌드 종료 코드와 로그, 고정 소스 목록, dist와 ASAR, 배포 문서·제3자 고지, EXE 신원, 설치 파일·체크섬의 전체 bytes/SHA256을 연결합니다. 검사 프로필·개인 자료·개발 출력은 제품과 공개 소스에 포함하지 않습니다.
- 정확한 공개 커밋의 Windows CI 결과를 확인합니다. 로컬 Windows 11 x64/RTX 5080/150% 배율과 CI의 가상 환경은 다른 검증 조건입니다.
- 공개 태그·릴리스·설치 파일·체크섬이 일치하는지 확인하고, 인증 없이 내려받은 전체 파일을 승인한 로컬 산출물과 대조합니다.

설치 파일은 미서명이며 업데이트는 수동입니다. 제거 프로그램의 존재와 앱 데이터 삭제 설정의 확인을 실제 제거 시험으로 표현하지 않습니다. 이상적인 부력 모형으로 실물 재료나 선박·인명 안전을 인증할 수 없습니다.
