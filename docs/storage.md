# 실험 보관과 원문 보호

`.buoyancy.json`은 현재 조건, 이름이 붙은 보관 비교 하나, 표시 선택과 카메라를 담습니다. 현재 조건과 비교는 각각 질량(kg), 체적(m³), 액체 밀도(kg/m³), 모드, 고정 시 물체 아랫면 높이(m)를 보관합니다. 화면의 L·cm는 파일에서 SI 단위로 저장됩니다.

모형 식별자는 `buoyancy-static-1`, 파일 형식 버전은 1입니다. 앱 1.0에서도 이 형식을 유지합니다. 힘·압력·수면·대표 위치는 저장하지 않고 입력으로부터 다시 계산합니다. 이 앱에는 시간 적분이나 재생 상태가 없습니다. 안내 실험의 진행·완료 표시도 파일에 포함하지 않습니다. 자유부유 모드의 고정 높이 값은 다음 모드 전환을 위해 기억하는 값이며 현재 물체 위치가 아닙니다.

파일 열기는 수치·범위·알 수 없는 필드·모형 버전을 엄격히 검사합니다. 잘못된 파일을 임의로 고쳐서 열지 않습니다. 파일 앞의 UTF-8 BOM 한 개는 허용하며 크기 한도는 10 MiB입니다. 실패한 가져오기는 현재 관찰과 선택한 원본 파일을 변경하지 않습니다.

데스크톱 저장은 같은 폴더에 새 임시 파일을 완전히 쓰고 flush·close한 뒤 대상 파일을 교체합니다. Windows의 일시적 공유 잠금은 제한된 횟수만 재시도하고 매번 대상 경로를 다시 확인합니다. 기존 대상을 먼저 삭제하지 않으며 끝내 실패하면 원본을 유지합니다. 연결 파일이나 연결된 상위 폴더 대신 일반 파일 경로를 사용합니다.

자동 저장 키는 `buoyancy-lab-project-v1`입니다. 손상되거나 더 새로운 형식의 자동 저장은 원문 보호 화면에서 그대로 내려받을 수 있습니다. 원문 보호 중에는 실험 조건을 바꾸어도 보호된 원문을 덮어쓰지 않습니다. 카메라 값이 없는 파일은 현재 조건의 기본 전체 보기로 엽니다. 힘 가까이 보기로 바뀐 시점도 기존 카메라 필드에 보관하며 별도의 모드나 계산 결과를 추가하지 않습니다.

데스크톱은 앱 전용 프로필을 사용합니다. 일반적인 새 버전 설치는 같은 앱 이름·저장 origin을 유지하도록 설계되어 있습니다. 검사용 프로필은 사용자 기본 프로필과 분리합니다. 특정 버전의 실제 설치·업데이트 검증 여부는 해당 버전의 결과 기록을 따릅니다.
