# Buoyancy Lab 상세 관찰의 계산 기준

상세 관찰은 기존 `buoyancy-static-1`의 정적 해를 읽어 면별 압력 힘·작용점·액체 질량·높이 감도를 계산한다. 기존 solver, 저장 schema 1, 원래 물리 입력과 보관한 비교 조건을 바꾸지 않는다. 낙하·침강·진동의 시간, 속도, 궤적을 새로 계산하지 않는다.

## 한 면의 압력중심과 부심

좌표는 기존과 같이 +Y가 위, 수조 바닥이 y=0이다. 물체는 수평 중심 x=z=0을 유지한다. 물체 밑면 높이를 b, 잠긴 높이를 h, 한 옆면의 수평 폭을 w라고 하자. `pb`는 밑면 압력, `pt`는 젖은 구간 윗끝의 압력이다. 부분잠김에서는 젖은 윗끝이 수면이므로 pt=0이며, 완전잠김에서는 기존 윗면 압력과 같다. 모두 대기압을 뺀 게이지 압력이다.

```text
한 옆면의 젖은 면적 A = w h
평균 압력 = (pb + pt)/2
한 옆면 압력 합력의 크기 F = w h (pb + pt)/2
압력중심 높이 yCP = b + h (pb + 2pt) / [3(pb + pt)]
부심 높이 yB = b + h/2
```

압력중심은 해당 **한 면**의 압력 1차모멘트를 합력으로 나눈 위치다. 위 식은 `∫p dA`와 `∫y p dA`에서 직접 얻는다. 부분잠김에서는 yCP=b+h/3, 부심은 b+h/2이다. 완전잠김에서도 압력중심은 젖은 옆면의 기하학적 중심보다 아래이며, 아주 깊어져 압력 분포가 상대적으로 균일해질수록 중심에 가까워진다. 이를 부심이 이동한 것이라고 해석하지 않는다.

물체가 건조하면 젖은 면적과 압력 합력은 0이며 압력중심과 부심은 `null`이다. 압력 합력이 0인 면에는 임의의 압력중심을 만들지 않는다. 수평 밑면과 윗면은 압력이 균일하므로 합력이 있을 때 각 면의 중심이 압력중심이다.

`areaM2`는 현재 젖은 부분, `fullFaceAreaM2`는 건조 부분을 포함한 면 전체의 기하학적 면적이다. 기존 모형이 완전잠김으로 분류한 윗면이 정확히 수면에 닿으면 전체 윗면 접촉 면적은 있지만 게이지 합력은 0이고 압력중심은 `null`이다. 건조 분기에서 수면에 닿기만 한 밑면의 젖은 면적은 0으로 표시한다. 이 접촉 면적 규약은 힘이나 원래 잠김 분기를 바꾸지 않는다.

## 여섯 면의 방향과 합력

액체가 물체에 가하는 압력 힘은 항상 면 안쪽으로 향한다.

| 면 | 압력중심의 고정 좌표 | 힘 방향 |
| --- | --- | --- |
| bottom | x=z=0, y=b | +Y |
| top | x=z=0, y=물체 윗면 | −Y |
| left | x=−0.05 m, z=0 | +X |
| right | x=+0.05 m, z=0 | −X |
| front | x=0, z=+0.05 m | −Z |
| back | x=0, z=−0.05 m | +Z |

반대 옆면의 힘은 같은 크기로 상쇄된다. 위아래 면의 압력 힘을 합하면 기존 부력 `ρgVs`가 된다. **압력 합력과 부력은 같은 힘의 두 설명**이므로 서로 다시 더하지 않는다. 부심은 잠긴 체적의 중심이고, 부력의 수직 작용선 위에 놓인다. 부심을 여섯 면 압력의 단일 ‘압력중심’이라고 부르지 않는다. 이 모형은 물체의 방향을 고정하며 회전·전복 안정성을 계산하지 않는다.

깊이에 따른 압력과 표면 힘의 합으로 부력을 설명하는 물리적 관계는 [OpenStax §14.4](https://openstax.org/books/university-physics-volume-1/pages/14-4-archimedes-principle-and-buoyancy)와 같다. 새 작용점 계산과 도식은 이 앱의 직육면체·정수압장에 대해 직접 적분한 관찰이다.

## 액체 질량과 수조 바닥 하중

```text
실제 액체 질량 = ρ Vf
배제한 가상 액체 질량 = ρ Vs
수면 상승 = H − H0 = Vs/At
수조 바닥 게이지 압력 = ρgH
액체가 수조 바닥에 가하는 하중 = ρgH At
                             = ρgVf + ρgVs
```

38.5 L로 일정한 것은 실제 액체의 **체적**이다. 유체 밀도를 바꾸면 실제 액체 질량도 바뀐다. 배제한 액체 질량은 물체가 차지하는 공간에 대응하는 가상 질량이며 실제 액체가 수조에서 없어졌다는 뜻이 아니다.

허용 범위에서 물체 밑면은 바닥에서 떨어져 있고 액체는 수조 바닥 전체를 덮는다. 따라서 바닥 게이지 압력은 수평면에서 균일하다. 바닥 액체 하중은 실제 액체 무게와 물체가 액체에 가하는 부력 반작용의 합이다. 수조 유리·장치 자체의 무게, 고정 프레임을 거쳐 전달되는 하중, 지지대 강도와 응력은 포함하지 않는다. 자유평형이 없는 무거운 물체의 기준 그림에서도 이것은 그 위치의 정수압장에 대한 관계이며, 물체가 그곳에 정지할 수 있다는 주장이 아니다.

세 보존 잔차는 면 압력 합력−기존 부력, `At H−Vs−Vf`, 바닥 액체 하중−액체 무게−기존 부력이다. 부호 있는 부동소수점 잔차를 강제로 0으로 바꾸지 않는다. 실제 측정 오차나 미래 상태 예측의 신뢰도를 나타내지 않는다.

## 물체 노출과 수면 여유

`exposedHeightM`는 물체 높이에서 잠긴 높이를 뺀 **물체 자체의 미잠김 길이**다. `topSurfaceClearanceM`는 윗면 높이−수면 높이이며 완전잠김에서 음수가 된다. 건조한 물체는 밑면과 수면 사이에 공기 틈이 있을 수 있어 두 값이 다르다. `tankHeadroomM`는 수조 상단−수면, `bottomClearanceM`는 물체 밑면−수조 바닥이다. 서로 다른 위치 기준을 한 값으로 합치지 않는다.

## 높이 고정에서의 정적 감도

질량·체적·밀도를 유지한 채 높이 고정 입력 b를 아주 조금 바꾸는 경우만 다룬다. 부분잠김 구간에서 수조의 실제 수면까지 함께 달라지므로 다음과 같다.

```text
dH/db = −Ab/(At−Ab)
dVs/db = −Ab At/(At−Ab)
dFb/db = −ρg Ab At/(At−Ab)
dFhold/db = +ρg Ab At/(At−Ab)
유한 수조 배율 = At/(At−Ab) = 35/33
```

ρ=1000 kg/m³일 때 높이당 구속힘 변화는 약 104.009924 N/m이다. 수면을 고정한 무한히 넓은 수조의 `ρgAb`보다 크다. 이는 정적 조건 변화율이며 실제 스프링 강성이나 동적 시스템의 고유진동수·진동 에너지·침강 속도를 계산한 것이 아니다.

완전잠김과 건조의 **구간 내부**에서는 수면·부력·구속힘의 높이 미분이 0이다. 건조 접촉점 b=H0와 완전잠김 접촉점 b=(Vf+V)/At−물체높이에서는 양쪽 기울기가 달라 하나의 미분값이 없다. 그 경계 및 `32×Number.EPSILON×대표 높이` 이내의 좌표 반올림 범위는 보수적으로 `differentiable=false`와 `null`을 반환한다. 이 작은 여유는 원래 잠김 분류나 실제 힘을 바꾸거나 작은 압력을 0으로 숨기는 데 사용하지 않는다.

자유평형 모드에서는 기억한 `heldBottomM` 입력이 현재 위치를 정하지 않는다. 따라서 높이 고정 감도는 `applicable=false`이며 수치는 `null`이다. 자유평형의 위치 민감도나 운동 응답을 대신해 표시하지 않는다. 중성 판정의 원래 64 ULP 허용오차와 작은 부호 있는 합력도 그대로 유지한다.

## 순수 API

`buoyancyDetail(snapshot)`는 다음 그룹을 반환한다. 모든 수치는 SI이며 설명용 사실표에서 cm·cm²·L로 변환한다.

| 그룹 | 필드 |
| --- | --- |
| `fluid` | `massKg`, `weightN`, `displacedMassKg`, `waterRiseM`, `tankHeadroomM`, `bottomGaugePressurePa`, `bottomFluidLoadN` |
| `body` | `exposedHeightM`, `topSurfaceClearanceM`, `bottomClearanceM`, `centerOfBuoyancyM` |
| `faces` | `bottom`, `top`, `left`, `right`, `front`, `back` |
| 각 face | `areaM2`, `fullFaceAreaM2`, `meanGaugePressurePa`, `forceN:{x,y,z}`, `centerOfPressureM:{x,y,z} 또는 null` |
| `balance` | `pressureResultantN:{x,y,z}`, `buoyancyResidualN`, `volumeResidualM3`, `tankLoadResidualN` |
| `sensitivity` | `applicable`, `branch`, `differentiable`, `waterLevelPerBottom`, `buoyancyPerBottomNPerM`, `holdingPerBottomNPerM`, `finiteTankFactor` |

`body.centerOfBuoyancyM`는 원래 snapshot처럼 **+Y 높이인 scalar 또는 null**이다. 각 face의 압력중심은 3D 위치다. `branch`는 `inactive`, `dry-contact`, `full-contact`, `dry`, `partial`, `full` 중 하나이며 표시에서는 적용 가능 여부와 null을 우선한다.

`describeBuoyancyDetail(partId, snapshot, detail?)`는 기존 14개 부품에 `{facts, note}`를 반환한다. 각 행은 `{label,value,unit,digits}`이며 최대 여섯 행이다. detail 모듈은 `model.js`만 불러오고 geometry·renderer·저장 schema·시간에 의존하지 않는다. 원래 strict 설정에서 다시 계산한 snapshot과 일치하는지 검사하며 입력을 보정하지 않는다. 반환 좌표는 입력과 분리된 객체이고 상세값을 원래 실험이나 비교에 저장하지 않는다.

## 독립 검증

`node --test tests/detail-model.test.mjs`는 기존 검사를 보완한다. 기존 5,022개 조건 검사가 주로 전체 힘·체적을 확인하므로 새 검사는 서로 상쇄되기 전의 **한 옆면 압력과 1차모멘트**에 집중한다.

- 액체 점유 단면적 적분과 독립 이분법으로 수면을 구한 뒤, 수면에서 나눈 Simpson 면 적분과 압력중심을 비교한다.
- 여섯 면의 inward 부호, 정확한 수평 상쇄, 위아래 합력과 부력의 동일성을 확인한다.
- 완전잠김 깊이 변화에서 두 수평면 압력의 동일 증가·부력 불변·옆면 압력중심 변화를 확인한다.
- 건조, 수면 접촉, 작용점 null, 작은 양의 잠김, 평균 압력·젖은 면적·전체 면적을 구분한다.
- 독립 수면 이분법의 중심차분으로 유한 수조 감도를 확인하고 두 접촉 경계의 서로 다른 단측 미분을 비교한다.
- 액체 질량·배수 질량·수조 바닥 하중 보존, 자유평형·중성 ULP·평형 없는 참조 그림의 원래 부호를 확인한다.
- 모든 부품 사실표의 단위 환산, 입력 거부, 동결한 원본·비교·저장 문자열 불변과 반환 객체 분리를 검사한다.
