# 문제 보고

[문제 보고 페이지](https://github.com/Ulsancl/buoyancy-lab/issues/new)에 앱 버전, Windows 버전, GPU, 화면 배율·해상도, 재현 순서와 기대/실제 결과를 적어 주세요. 물체 질량 kg, 체적 L, 액체 밀도 kg/m³, 자유부유/높이 고정 모드, 높이 고정이면 아랫면 높이 cm도 필요합니다. 현재 조건인지 보관 비교인지 구별해 주세요.

힘 표시 문제라면 위·아래 방향과 N 수치, 선택 요소, 시점, 앞벽 열기와 힘/압력 표시 여부를 함께 적어 주세요. 화면의 cm·L와 파일의 m·m³를 구별하세요. 수치 문제에는 확인한 공식이나 출처가 있으면 도움이 됩니다.

이 앱은 이동 시간·낙하 속도·동적 침강·파동·회전·전복·바닥 접촉·표면장력·공기 부력을 계산하지 않습니다. 중성부력의 여러 가능한 높이나 평형이 없는 무거운 물체의 기준 위치는 모형 설명을 함께 확인하세요.

손상되거나 더 새로운 형식의 파일은 먼저 원문을 별도 보관하고 덮어쓰지 마세요. 전체 사용자 프로필을 공개할 필요는 없습니다. 비교 이름·개인 경로·진단 로그를 확인한 뒤 필요한 작은 자료만 공유하세요. 문제 보고는 응답 시간, 모든 기기 호환성 또는 유료 유지보수 계약을 보장하지 않습니다.
