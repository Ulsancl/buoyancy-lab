# 로컬 자료와 개인정보

설치 앱은 부력 계산과 화면 관찰에 필요한 기능을 로컬에 포함합니다. 계정·광고·원격 분석·자동 오류 전송 기능을 구현하지 않습니다. 앱 화면의 외부 HTTP/HTTPS 요청과 외부 창은 차단합니다. 개발 의존성·검사 도구 준비와 릴리스 다운로드는 별도이며 인터넷을 사용할 수 있습니다.

파일 열기·저장은 사용자가 선택한 로컬 파일을 대상으로 합니다. 자동 저장·창 위치·실행 로그는 Buoyancy Lab의 로컬 프로필에 남습니다. 비교 이름, 현재와 보관 조건, 표시 선택, 관찰 시점은 실험 파일에 포함됩니다. 원문 복구는 사용자의 선택으로 로컬 파일에 내보냅니다.

문제 보고 전에 비교 이름·파일 내용·로그·스크린샷을 확인하세요. 진단 자료에 개인 경로가 포함될 수 있으므로 재현에 필요한 작은 자료만 직접 공유하세요. 앱이 자료를 자동 제출하지 않으며 자동 저장은 별도 백업을 대신하지 않습니다.
