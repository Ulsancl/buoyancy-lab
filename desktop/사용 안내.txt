Buoyancy Lab 1.1.0 — 정적 부력 교육용 실험 앱

질량·체적·액체 밀도를 바꾸고 자유부유 평형과 높이 고정을 비교합니다.
처음 조건은 0.4 kg / 1 L / 1000 kg/m³입니다. 이 조건의 잠김 비율은 40%입니다.
화면에 L·cm로 보이는 체적·높이는 파일 안에서 m³·m로 보관됩니다.

자유부유 평형: 가벼운 물체의 잠김량을 계산합니다. 중성부력은 여러 완전잠김 높이에서 평형이며 그림은 대표 위치입니다. 무거운 물체는 자유부유 평형이 없고, 그림은 정수압 힘을 읽는 완전잠김 기준 위치입니다.
높이 고정: 물체 아랫면의 바닥 기준 높이를 지정합니다. 양방향 고정구는 필요에 따라 위로 당기거나 아래로 누릅니다. 완전잠김 물체는 더 깊어져도 배제 체적과 부력이 같고 위·아래 면의 압력이 함께 증가합니다.

모형은 유한한 수조의 액체 체적을 보존하므로 물체가 잠기면 수면도 올라갑니다.
정적 계산이며 낙하·부상 시간이나 속도를 재생하지 않습니다. 파동·회전·전복·바닥 접촉·표면장력·공기 부력은 계산하지 않습니다. 물체와 바닥 사이에는 간격이 있습니다. 실제 선박이나 인명 안전을 판단하는 도구가 아닙니다.

힘 표시를 켜면 화살표 옆에서 방향과 N 수치를 함께 읽습니다. 힘 가까이 보기는 현재 물체와 힘 화살표를 확대합니다. 화살표 길이는 항상 3 mm/N이며 확대를 위해 수치를 바꾸지 않습니다. 힘 표시가 꺼져 있으면 이 버튼도 비활성화됩니다.
0 N은 방향 없는 수치로 표시하고 화살표를 만들지 않습니다. 0.01 N 미만의 비영 힘은 방향과 <0.01 N으로 구별합니다. 자유부유에서는 고정력을 사용하지 않습니다. 질량 kg, 힘 N, 압력 Pa를 구별하세요. 표면 압력과 그 결과인 부력을 별개의 추가 힘으로 더하지 않습니다.
관찰 대상 선택과 표시 전환은 실험 조건을 바꾸지 않습니다. 선택 부품 집중과 힘 가까이 보기처럼 명시적인 관찰 버튼만 카메라를 이동합니다. 비교 보관은 현재 조건의 복사본을 유지합니다.

상세 압력판은 여섯 면의 액체 힘, 한 옆면의 압력중심과 부심을 구별합니다. 압력 합력이 이미 부력이므로 두 값을 더하지 않습니다. 높이 감도는 작은 조건 변화의 정적 기울기이며 운동 시간·진동을 계산하지 않습니다. 수면 접촉 경계에서는 단일 기울기를 표시하지 않습니다.
구조·압력 자세히는 임시 관찰입니다. 원래 관찰로 돌아가기에서 카메라를 복원하고 관찰 중 저장한 파일에도 원래 시점을 기록합니다. 무체적 점선 연결과 양방향 고정 힘은 이상적인 정적 구속입니다.

파일 메뉴: 새 실험 Ctrl+N / 열기 Ctrl+O / 저장 Ctrl+S
실험 메뉴: 자유부유 평형 Ctrl+Shift+E / 높이 고정 Ctrl+Shift+H
보기: 3D 크게 보기 Ctrl+Shift+F / 전체 화면 F11
도움말: F1

실험 파일은 .buoyancy.json입니다. 현재 조건·보관 비교·시점을 저장하며 힘과 압력은 열 때 다시 계산합니다. 안내 진행은 저장하지 않습니다. 잘못되거나 더 새로운 형식의 원문을 자동 수정하지 않습니다. 원문 보호 화면에서 원본을 별도 보관할 수 있습니다.

설치 파일은 코드 서명되지 않았고 자동 업데이트가 없습니다. 새 버전은 설치 파일과 SHA256을 확인한 뒤 직접 설치합니다. 중요한 실험은 먼저 별도 파일로 보관하세요. 제3자 구성 요소의 원문 고지는 설치 폴더에 함께 포함됩니다. 실제 검증 환경과 결과는 각 릴리스의 기록을 따릅니다.
